QEMU used for the tests
- QEMU 8.2.2 (-M pc: PIIX3 IDE in compatibility mode, 8086:7010,
  programming interface 80h; -M q35: no IDE function at all), patched
  (test environment only):
  - ATA disks with 1024/2048/4096-byte logical sectors (IDENTIFY words
    106/117-118) on the IDE bus.
  - The PIIX3 function reporting another device ID (ICH4 24CB) for the
    Intel timing-register path.
  - The CMD646 (1095:0646) PCI IDE controller built into the x86
    targets: native mode on both channels (programming interface 8Fh),
    one PCI INTA for both channels (level-sensitive, shared).
    SeaBIOS writes the legacy addresses 1F0h/3F4h/170h/374h into BAR 0-3
    of every native IDE function, which would make it decode the same
    ports as the PIIX3; with CMD646_BARS=e000 those writes are moved to
    E000h/E010h/E020h/E030h, as a BIOS that assigns free I/O space would
    do. Bus master (BAR 4) as SeaBIOS assigned it.
    CMD646_BARMASK=<hex>: only the BARs whose bit is set are moved
    (1 = BAR 0 ... 8 = BAR 3), the others stay on the legacy ports.
  - CMD646_STICKY=1: the CMD646 interrupt latches stay set until
    software writes 1 to them (CFR/ARTTIM23 in config space, MRDMODE
    bits 2/3 at bus master base + 1), and the PCI interrupt follows the
    latches, as on the real chips. Stock QEMU drops a latch when the
    drive drops INTRQ, which hides the problem.
  - CMD646_DEVID=0643/0648/0649[:rev]: the CMD646 model reports another
    member of the family (or revision).
  - IDE_PCI_DEVID=<vendor>:<device>[:<revision>]: the PIIX3 function
    reports another vendor/device (unknown controller, ALi M5229,
    RZ1000, CMD640, ServerWorks OSB4); its registers stay PIIX3's.
  - IDE_SIMPLEX=1: the bus master status reports bit 7 (simplex).
  - The SiI3112 model (1095:3112, class 0104, BAR 5 registers with
    SIEN) built into the x86 targets.
- QEMU's bus master is an SFF-8038i engine with PRDs; UDMA/MWDMA
  timing registers are accepted but have no effect on speed. The
  "modes" the driver reports (MWDMA 2 on PIIX3, UDMA 5 on ICH4) are
  what SET FEATURES and the timing registers were programmed to.
- Tools (sources in the tools folder of the work tree, not shipped):
  idetest (GET_INFO, SMART, pass-through, MODE SELECT, VERIFY,
  START STOP UNIT, power IOCTL), bench (QD32 4K write/read, 50 MB
  sequential verify by CRC), sumtool (CRC of a directory tree),
  secdump (sector dump), geom (geometry/capacity per drive), devstat
  (device node status, 2000/XP), hiio (64 KB write/read/compare at any
  offset of a raw disk, with a page-aligned buffer and with buffers
